9  Operações com data frames em R base

Ordenar, combinar, agregar e selecionar

Autor

Alexandre Nicolella

9.1 Introdução

Nos capítulos anteriores, construímos objetos, importamos bases e verificamos a qualidade dos dados. Agora retomaremos o material original para realizar operações diretamente com as funções do R base.

Nosso objetivo será ordenar os estados, combinar as bases de feminicídios e tentativas, calcular resumos por região e criar subconjuntos sem modificar os arquivos originais.

NotaObjetivos do capítulo

Ao final deste capítulo, você deverá ser capaz de:

  • ordenar as linhas de um data frame;
  • identificar e verificar uma chave de combinação;
  • combinar bases com merge();
  • agregar informações por grupo;
  • selecionar e excluir variáveis;
  • selecionar observações por condições lógicas;
  • conferir as dimensões depois de cada transformação.

9.3 Combinando as duas bases

Temos um data frame com homicídios e feminicídios e outro com tentativas. Para combiná-los, precisamos de uma chave presente nas duas tabelas. A variável sigla identifica cada unidade da federação.

Antes da combinação, devemos verificar se a chave está preenchida e não se repete:

anyNA(df_feminic22$sigla)
[1] FALSE
anyNA(df_t_feminic22$sigla)
[1] FALSE
anyDuplicated(df_feminic22$sigla)
[1] 0
anyDuplicated(df_t_feminic22$sigla)
[1] 0

Realizamos a combinação com merge():

df_final_feminic_22 <- merge(
  df_feminic22,
  df_t_feminic22,
  by = "sigla",
  all = TRUE,
  suffixes = c("", "_tent")
)

dim(df_final_feminic_22)
[1] 27 16
names(df_final_feminic_22)
 [1] "sigla"          "estado"         "regiao"         "homic_abs"     
 [5] "homic_tx"       "feminico_abs"   "feminic_tx"     "part_feminic"  
 [9] "rendapc"        "estado_tent"    "regiao_tent"    "t_homic_abs"   
[13] "t_homic_tx"     "t_feminic_abs"  "t_feminic_tx"   "part_t_feminic"

O argumento all = TRUE mantém as linhas encontradas em qualquer uma das bases. Como estado e regiao existem nos dois arquivos, o R acrescenta o sufixo _tent às colunas vindas da segunda base.

Conferimos se todas as siglas esperadas estão presentes:

setdiff(df_feminic22$sigla, df_final_feminic_22$sigla)
character(0)
setdiff(df_t_feminic22$sigla, df_final_feminic_22$sigla)
character(0)
ImportanteCombinar exige uma chave adequada

Uma chave repetida pode multiplicar linhas durante a combinação. Antes de usar merge(), verifique o que cada linha representa e se a chave deveria ser única em cada tabela.

9.4 Organizando o resultado da combinação

As colunas estado_tent e regiao_tent repetem informações já existentes. Antes de retirá-las, verificamos se os valores coincidem:

all(df_final_feminic_22$estado == df_final_feminic_22$estado_tent)
[1] TRUE
all(df_final_feminic_22$regiao == df_final_feminic_22$regiao_tent)
[1] TRUE

Depois da conferência, construímos um novo objeto sem as colunas redundantes:

final_fem_22 <- df_final_feminic_22[
  setdiff(
    names(df_final_feminic_22),
    c("estado_tent", "regiao_tent")
  )
]

names(final_fem_22)[
  names(final_fem_22) == "feminico_abs"
] <- "feminic_abs"

names(final_fem_22)
 [1] "sigla"          "estado"         "regiao"         "homic_abs"     
 [5] "homic_tx"       "feminic_abs"    "feminic_tx"     "part_feminic"  
 [9] "rendapc"        "t_homic_abs"    "t_homic_tx"     "t_feminic_abs" 
[13] "t_feminic_tx"   "part_t_feminic"

Usar o nome da coluna é mais seguro do que depender apenas de sua posição, pois a ordem pode mudar quando a base for atualizada.

AvisoCuidado ao retirar colunas

Evite retirar repetidamente colunas do mesmo objeto por posição. Crie um novo objeto ou selecione explicitamente os nomes que devem permanecer. Assim, o código pode ser executado novamente sem produzir resultados diferentes.

9.5 Agregando por região

Podemos calcular médias das variáveis numéricas para cada região. Primeiro identificamos as colunas numéricas:

variaveis_numericas <- vapply(final_fem_22, is.numeric, logical(1))
names(final_fem_22)[variaveis_numericas]
 [1] "homic_abs"      "homic_tx"       "feminic_abs"    "feminic_tx"    
 [5] "part_feminic"   "rendapc"        "t_homic_abs"    "t_homic_tx"    
 [9] "t_feminic_abs"  "t_feminic_tx"   "part_t_feminic"

Em seguida, utilizamos aggregate():

regiao_media <- aggregate(
  final_fem_22[variaveis_numericas],
  by = list(regiao = final_fem_22$regiao),
  FUN = mean,
  na.rm = TRUE
)

Podemos manter apenas a sigla e as participações de feminicídios e tentativas:

variaveis_selecionadas <- c(
  "sigla",
  "part_feminic",
  "part_t_feminic"
)

feminic_sel <- final_fem_22[variaveis_selecionadas]

fem_n_ne <- final_fem_22[

fem_n_ne_50 <- final_fem_22[

     final_fem_22$regiao == "NE") &
    final_fem_22$part_feminic >= 50,
