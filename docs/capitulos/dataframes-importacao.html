7  Data frames e importação

Dos arquivos jurídicos à base de dados

Autor

Alexandre Nicolella

7.1 Introdução

Na prática, uma base raramente será digitada por inteiro. Os dados podem chegar em planilhas, arquivos de texto ou formatos produzidos por outros programas. Neste capítulo, utilizaremos bases sobre homicídios de mulheres, feminicídios e tentativas para compreender a estrutura de um data frame e os procedimentos de importação e exportação.

7.2 Linhas, colunas e unidade de observação

Em um data frame, cada linha representa uma unidade de observação e cada coluna representa uma variável. Nas bases utilizadas aqui, a unidade de observação é o estado brasileiro.

Antes da leitura, precisamos saber:

  • qual é a unidade de observação;
  • o que significa cada variável;
  • qual separador delimita as colunas;
  • qual símbolo representa a parte decimal dos números;
  • como ausências e categorias foram registradas;
  • qual é a codificação de caracteres;
  • qual é a fonte e a data de obtenção dos dados.

Os arquivos originais devem permanecer na pasta dados. Arquivos tratados ou exportados devem ser gravados em outra pasta, por exemplo dados/tratados, para que o trabalho possa ser reproduzido sem modificar a fonte original.

7.3 Importando arquivos CSV

Apesar do nome comma-separated values, um arquivo CSV pode utilizar diferentes caracteres para separar os campos. Nas duas bases deste capítulo, o ponto e vírgula separa as colunas e o ponto marca a parte decimal.

df_feminic22 <- read.table(
  "dados/dados_feminic.csv",
  header = TRUE,
  sep = ";",
  dec = ".",
  fileEncoding = "UTF-8",
  na.strings = c("", "NA"),
  check.names = FALSE
)

df_t_feminic22 <- read.table(
  "dados/dados_tent_feminic.csv",
  header = TRUE,
  sep = ";",
  dec = ".",
  fileEncoding = "UTF-8",
  na.strings = c("", "NA"),
  check.names = FALSE
)

Os argumentos utilizados têm funções distintas:

Argumento Função
header = TRUE informa que a primeira linha contém os nomes das variáveis
sep = ";" define o ponto e vírgula como separador de campos
dec = "." define o ponto como marcador decimal
fileEncoding = "UTF-8" informa a codificação dos caracteres
na.strings = c("", "NA") indica como os valores ausentes aparecem no arquivo
check.names = FALSE preserva os nomes originais das colunas

7.3.1 read.csv(), read.csv2() e read.table()

As três funções pertencem ao R básico. read.csv() pressupõe vírgula entre os campos e ponto decimal. read.csv2() pressupõe ponto e vírgula entre os campos e vírgula decimal. read.table() permite declarar essas escolhas explicitamente.

# Vírgula entre campos e ponto decimal
dados <- read.csv("dados/arquivo.csv")

# Ponto e vírgula entre campos e vírgula decimal
dados <- read.csv2("dados/arquivo.csv")

# Ponto e vírgula entre campos e ponto decimal
dados <- read.table(
  "dados/arquivo.csv",
  header = TRUE,
  sep = ";",
  dec = "."
)

Não basta escolher a função pelo nome ou pela extensão do arquivo. É necessário abrir o CSV em um editor de texto ou consultar sua documentação para identificar o separador de campos e o marcador decimal efetivamente utilizados.

7.5 Importando uma planilha do Excel

Uma pasta de trabalho do Excel pode conter uma ou várias abas. Mesmo quando existe apenas uma, podemos informar seu nome explicitamente. Isso torna o código mais claro e evita ambiguidades caso outras abas sejam acrescentadas posteriormente.

O arquivo de exemplo possui somente a aba feminicidio:

# Requer o pacote readxl
readxl::excel_sheets("dados/dados_feminic.xlsx")

df_feminic_excel <- readxl::read_excel(
  "dados/dados_feminic.xlsx",
  sheet = "feminicidio"
)

O argumento sheet pode receber o nome ou a posição da aba. Usar o nome costuma deixar o script mais compreensível.

7.8 Comparando os formatos

Formato Característica principal Uso frequente
CSV arquivo de texto simples e interoperável intercâmbio de dados entre programas
Excel organiza dados em planilhas e abas consulta e troca com usuários de planilhas
Stata preserva formatos utilizados pelo Stata intercâmbio com projetos desenvolvidos no Stata
RDS preserva a estrutura de um objeto do R armazenamento intermediário em projetos de R

7.9 Exportando uma base

Uma base tratada deve ser gravada em uma pasta diferente dos dados originais. Os blocos desta seção não são executados automaticamente porque criam ou substituem arquivos no computador.

7.9.1 Exportando CSV

Para manter a convenção dos arquivos utilizados neste capítulo, definimos ponto e vírgula entre campos e ponto decimal:

write.table(
  df_feminic22,
  "dados/tratados/feminicidios_2022.csv",
  sep = ";",
  dec = ".",
  row.names = FALSE,
  fileEncoding = "UTF-8",
  na = ""
)

Se o destino exigir vírgula decimal, podemos alterar dec = ",". O separador e o marcador decimal devem ser definidos de acordo com o programa e a convenção de quem receberá o arquivo.

7.9.2 Exportando Excel

No Excel, o nome atribuído ao elemento da lista torna-se o nome da aba. Neste exemplo, o arquivo terá apenas a aba feminicidio:

# Requer o pacote writexl
writexl::write_xlsx(
  list(feminicidio = df_feminic22),
  "dados/tratados/feminicidios_2022.xlsx"
)

7.9.3 Exportando Stata

Mantendo o procedimento do material original:

foreign::write.dta(
  df_feminic22,
  "dados/tratados/feminicidios_2022.dta"
)

Também é possível utilizar haven::write_dta() quando o pacote haven estiver disponível.

7.9.4 Exportando RDS

saveRDS(
  df_feminic22,
  "dados/tratados/feminicidios_2022.rds"
)
ImportantePreserve os dados originais

Não sobrescreva os arquivos recebidos. Transformações e correções devem produzir uma nova base, recriável pelos scripts do projeto.
