11  Manipulação de dados com dplyr

Selecionar, transformar e resumir informações jurídicas

Autores

Alexandre Nicolella

José de Jesus Filho

11.1 Introdução

O dplyr fornece um conjunto consistente de funções para manipular dados. Cada função resolve uma tarefa específica, e o pipe permite reunir essas tarefas em um fluxo legível.

Continuaremos utilizando a base combinada de feminicídios e tentativas construída a partir dos dois arquivos originais.

NotaObjetivos do capítulo

Ao final deste capítulo, você deverá ser capaz de:

  • filtrar observações com filter();
  • selecionar, renomear e reposicionar variáveis;
  • ordenar linhas com arrange();
  • criar variáveis com mutate() e case_when();
  • produzir resumos com group_by() e summarise();
  • construir tabelas de frequência com count();
  • reunir as operações em um fluxo verificável.

11.3 Comandos para as linhas

Esses comandos modificam quais observações aparecem e em que ordem, sem alterar o significado das colunas. Neste bloco, utilizaremos filter() para selecionar linhas e arrange() para ordená-las.

sem_norte <- final_fem_22 |>

11.4 Comandos para as colunas

Esses comandos escolhem, renomeiam, reposicionam ou criam variáveis. Neste bloco, utilizaremos select(), rename(), relocate(), mutate() e case_when().

11.4.1 Selecionando variáveis

Montamos uma tabela apenas com as taxas de feminicídio e de tentativa de feminicídio:

taxas_feminicidio <- final_fem_22 |>
  select(sigla, feminic_tx, t_feminic_tx)

sem_nome_estado <- final_fem_22 |>

variaveis_taxa <- final_fem_22 |>

Podemos reunir as variáveis de feminicídio no início da tabela:

    feminic_tx,
    part_feminic,

11.4.4 Criando novas variáveis

Criamos proporções que relacionam os casos consumados com o total formado por casos consumados e tentativas:

final_fem_22_1 <- final_fem_22 |>
  mutate(
    feminic_efetivado =
      feminic_abs / (feminic_abs + t_feminic_abs),
    homic_efetivado =
      homic_abs / (homic_abs + t_homic_abs)
  )

Os valores devem ser interpretados com cautela: trata-se de uma construção a partir das variáveis disponíveis, e não de uma probabilidade individual de desfecho.

11.4.5 Criando categorias

O material original cria uma variável binária para valores de homic_efetivado iguais ou superiores a 0,30. Podemos expressar essa regra com case_when() e preservar ausências:

final_fem_22_1 <- final_fem_22_1 |>
  mutate(
    homi_efet_alto = case_when(
      is.na(homic_efetivado) ~ NA_integer_,
      homic_efetivado >= 0.30 ~ 1L,
      homic_efetivado < 0.30 ~ 0L
    )
  )

11.5 Comandos para resumos

Esses comandos condensam as observações em estatísticas ou contagens. Utilizaremos group_by() para definir grupos, summarise() para calcular medidas e count() para construir frequências.

11.5.1 Agrupando e resumindo

Calculamos a taxa média e o desvio-padrão por região:

feminic_agrupado <- final_fem_22 |>
  group_by(regiao) |>
  summarise(
    estados = n(),
    media_feminic = mean(feminic_tx, na.rm = TRUE),
    dp_feminic = sd(feminic_tx, na.rm = TRUE),
    .groups = "drop"
  )

sumario_geral <- final_fem_22 |>

11.6 Reunindo as operações

O fluxo seguinte mantém estados com informação disponível, cria a classificação, agrupa por região e resume os resultados:

resumo_regional <- final_fem_22 |>
  filter(!is.na(part_feminic)) |>
  mutate(
    participacao = case_when(
      part_feminic >= 50 ~ "50% ou mais",
      part_feminic < 50 ~ "menos de 50%"
    )
  ) |>
  group_by(regiao, participacao) |>
  summarise(
    estados = n(),
    taxa_media = mean(feminic_tx, na.rm = TRUE),
    .groups = "drop"
  ) |>
  arrange(regiao, desc(taxa_media))
